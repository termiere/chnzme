# chnzme

A Chinese learning platform focused on HSK preparation.

## HSK Vocabulary

Word lists for HSK 1–3 based on the 2026 HSK standard.

Each entry includes Chinese characters, pinyin, and translations in English and Russian.

Contributions with translations in other languages are welcome.

### Word Lists

- [HSK 1](data/hsk/hsk1.json) — 300 words
- [HSK 2](data/hsk/hsk2.json) — 200 words
- [HSK 3](data/hsk/hsk3.json) — 500 words
